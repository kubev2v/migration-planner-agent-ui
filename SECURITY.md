# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please report the issue to Red Hat Product Security:

- **Email:** secalert@redhat.com
- **Web:** https://access.redhat.com/security/team/contact

Please include as much detail as possible:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

Red Hat Product Security will acknowledge your report and work with you to address the issue.
